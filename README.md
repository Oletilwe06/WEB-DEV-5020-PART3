# WEB-DEV-5020-PART3

## Part 3: Enhancing Functionality and SEO

### Project Overview
OLE Foundation is a community support website designed to
provide information about the organisation, its services,
community activities and contact details.

### JavaScript Functionality
The website includes:
- Search functionality for filtering service information.
- A gallery lightbox for viewing enlarged images.
- Form validation for enquiry and contact forms.
- Interactive accordion sections.
- Mobile navigation interaction.
- A dynamic copyright year.

### Search Engine Optimisation (SEO)
SEO improvements include:
- Unique page titles and meta descriptions.
- Relevant keywords within page content.
- Descriptive image alternative text.
- Semantic HTML headings.
- Internal navigation links.
- A robots.txt file and XML sitemap.
- Responsive styling for mobile devices.

### Testing
The following tests should be completed:
- Test all navigation links.
- Search for services using different keywords.
- Open and close gallery images.
- Submit empty forms and check validation.
- Test valid and invalid email addresses.
- View the website on desktop and mobile screens.
- Check browser developer tools for errors.
